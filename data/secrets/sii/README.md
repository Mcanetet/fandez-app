# Secretos SII (no versionar .p12 ni CAF)

Coloca aquí (o configura rutas absolutas en env):

- `certificate.p12` — certificado digital
- `caf-33.xml` — CAF tipo 33 vigente (facturas de venta)
- `caf-46.xml` — CAF tipo 46 vigente (facturas de compra, p. ej. chatarra)
- `caf-61.xml` — CAF tipo 61 vigente (notas de crédito)
